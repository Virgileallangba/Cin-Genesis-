# 🎬 CINÉ-GENESIS

Studio de cinéma IA dans le navigateur. Créez un film complet en 7 étapes, propulsé par l'API xAI Grok.

## ✨ Fonctionnalités
- **Synopsis** : écriture et réécriture assistée
- **Personnages** : création avec portraits cohérents
- **Scènes** : génération automatique du script et des images
- **Plans** : découpage cinématographique et visuels
- **Vidéos** : génération vidéo par IA (Grok Imagine)
- **Téléchargement** : sauvegardez vos vidéos sur votre appareil

## 🚀 Utilisation
1. Ouvrez l'application : [Votre lien GitHub Pages]
2. Collez vos clés API xAI (une par ligne)
3. Choisissez un genre et laissez-vous guider !

## 🔑 Obtenir une clé API
Rendez-vous sur [console.x.ai](https://console.x.ai) pour générer votre clé.

## 📱 Compatibilité
Fonctionne sur ordinateur, tablette et mobile (iOS/Android).
